biografia

Una computadora funciona mediante la interacción de hardware (componentes físicos) y software (instrucciones). Los componentes internos esenciales incluyen la CPU (cerebro), Memoria RAM (almacenamiento temporal rápido), Almacenamiento (SSD/HDD para datos permanentes), Placa Base (conexión central) y la Fuente de Poder (energía).
